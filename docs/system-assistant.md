# 系统助手

网页侧栏和消息平台共用助手接口。助手读取实际结果，再选择下一步操作。
业务操作调用已有应用服务，沿用文档发布、版本、隐私、预算和模型许可规则。

## 操作范围

| 内容       | 支持的操作                                                     |
| ---------- | -------------------------------------------------------------- |
| 文档       | 导入、查找、读取原文、接收审核、修改正文、分段、翻译、确认发布 |
| 标签与联系 | 词表、结构化标注、主题成员、关系及原文证据                     |
| 来源       | 新增与修改、接收检查、拆分方案、来源质量、往期补收             |
| 查询       | 数据库搜索、知识库问答、联网搜索、综合回答、保存联网材料       |
| 报告       | 预览范围、创建、生成、编辑、计划、站内发布、Markdown 导出      |
| 任务与设置 | 队列开关、单项及批量任务控制、已有处理配置、外观、数据维护     |

具体工具及参数以接口的 `tools` 返回值为准。模型密钥、容器部署、主机命令和任意 SQL 不属于助手工具。
PDF 使用现有浏览器打印入口。消息平台的签名认证、用户绑定和发送接口由平台适配器提供，本版未接入具体平台。

## 执行与确认

读取结果直接返回。写入和付费业务调用先显示操作及参数，所有者确认后执行。
网页使用确认按钮。消息平台将待确认操作展示给所有者，再提交同一确认编号。
资料和模型输出中的指令无法代替所有者确认。

每条指令最多执行 16 步、调用 12 次指令模型。业务任务另用原有调用上限与预算。
每次请求和步骤结果保存到会话。后续指令可引用最近的结果。
模型返回错误、服务故障或达到上限时停止。助手不会自动补发模型请求。
已保存的读取结果可用于继续执行。写入结果不明时先核对目标内容。
业务任务提交后继续在原队列运行，助手通过任务编号读取进度。排队与完成分别显示。

私密资料和备份结果只返回所有者，不回传模型。公开查询结果可供模型总结。
助手访问密钥具有当前工作区的所有者权限；本项目仍为单所有者应用。

## 三个开关

- AI 总开关：关闭后停止发起模型调用。已发出的请求可以完成。
- 暂停后台队列：暂停文档、主题和报告的后续处理。助手仍可响应。
- 助手也遵守低价时段：默认开启。关闭后，指令模型可在其他时段调用；业务模型调用仍受原价格时段限制。

后两项位于“设置 → AI”。全局许可、并发和用量记录继续有效。
“暂停队列”“恢复队列”“暂停 AI”“恢复 AI”可直接解析，无需调用模型，仍需确认。

## 部署配置

设置 `STRUIINFO_ASSISTANT_TOKEN_FILE`，指向仓库外的只读密钥文件。
也可使用互斥的 `STRUIINFO_ASSISTANT_TOKEN` 进程变量。
密钥使用 32–256 位字母、数字、下划线或连字符，可用 `openssl rand -hex 32` 生成。
密钥独立于模型密钥和外部 Agent 令牌，不写入 runtime.env。
Docker 挂载该文件，并将容器内路径传给上述变量。未配置时助手接口关闭。
自然语言规划使用现有模型配置。云端入口使用 HTTPS 和现有访问认证。

浏览器密钥仅保存在当前页面内存中。刷新后需重新连接，会话继续保留。
会话文件位于 `dataRoot/assistant/<workspaceId>/`，随外部数据卷保留。
备份和恢复整个实例时应包含此目录。现有个人数据导出包不包含助手会话。
同一工作区由一个 API 进程写入会话。

## 通用接口

`POST /api/v1/assistant/commands`

请求头：`Authorization: Bearer <助手密钥>`、`Content-Type: application/json`。
请求体：`{"operation":"操作名","input":{}}`。成功返回 `{"result":...}`。

| operation | input                                                                      |
| --------- | -------------------------------------------------------------------------- |
| status    | `{}`；返回模型状态和单轮限制                                               |
| tools     | `{}` 返回工具目录；`name` 返回单项参数结构                                 |
| sessions  | `{}`；最近会话，包含 `version` 和 `active`                                 |
| delete    | `sessionId`、`expectedVersion`；删除指定版本的对话记录                     |
| open      | `channel`、`conversationId`；同一组合取得同一会话                          |
| read      | `sessionId`；当前步骤、待确认操作及后台任务                                |
| events    | `sessionId`、`after`；读取序号大于 after 的事件，返回 next 游标            |
| ask       | `sessionId`、`messageId`、`message`，可选 `timeZone`                       |
| invoke    | `sessionId`、`messageId`、`operation`、`input`；直接使用工具，保留确认规则 |
| confirm   | `sessionId`、`turnId`、`confirmationId`                                    |
| dismiss   | 同 confirm；取消待确认操作                                                 |
| resume    | `sessionId`；从已保存记录继续，保留原步骤及调用上限                        |
| cancel    | `sessionId`；停止助手后续操作，已提交业务任务另行控制                      |

`ask` 和 `invoke` 先返回执行回执，随后读取 `read` 或 `events`。
`confirmation` 表示待确认。`completed` 表示本条指令结束；后台任务进度见 `jobs` 和后续事件。
`failed`、`interrupted` 保留失败或中断记录。`uncertain: true` 表示写入结果待核对。
确认包含的业务版本仍会校验。版本已变化时重读目标，再提出新操作。
每个会话最多保存 100 条指令；已满时创建新会话。
历史对话可逐条删除，删除前需确认。正在执行的对话需先停止。
删除保留已创建的文档、报告和业务任务。删除当前对话后可直接输入新指令。

## 消息平台接法

1. 适配器校验平台签名和所有者身份。助手密钥放在适配器服务端。
2. 用稳定的 `channel` 和 `conversationId` 打开会话。它们用于路由，不承担认证。
3. 将平台消息编号作为 `messageId`，调用 `ask`，传入用户时区。
4. 读取事件，保存 `next` 游标，向原会话返回结果或确认选项。
5. 所有者确认后提交原 `turnId` 和 `confirmationId`。
6. 后台任务未结束时继续读取事件，返回完成或失败结果。

相同消息编号和内容返回已有执行记录。相同确认编号返回已有决定，不重复写入。
断线后沿用原编号重读或补交请求。相同编号对应不同内容会返回冲突。
网页可打开消息平台会话，查看并继续同一项操作。

## 验证范围

使用临时数据库和合成资料验证业务接口、持久化、确认、消息去重、恢复与网页交互。
多步规划使用合成模型响应验证。真实模型的指令理解质量与具体消息平台接入需另行验收。
