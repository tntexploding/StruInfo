# 文档处理说明

新文档执行审核、拆分、标注、确认发布。
主题归组与重点联系独立排队。
模型和外部 Agent 的阶段指令来自
[document_processing_standard.ts](../apps/server/src/modules/processing/document_processing_standard.ts)。
processing_standard 接口按阶段返回当前指令。

## 审核

核对正文完整性、来源、日期和接收范围。
保留接受、拒绝与待复核理由。
人工决定优先。原文和已有回答保留。

## 拆分

新任务冻结来源与格式方案。
连贯文章保持上下文，合集按独立内容拆分。
标题与正文依据绑定。导语、参考资料和附录保留覆盖关系。
结构写入检查完整范围与当前修订。

## 标注

标签与观点描述本条正文。
使用个人词表及已确认别名，保存原文依据。
人工标注优先。保存形成草稿。

## 发布与组织

基础发布检查整篇条目修订和接收决定。
确认内容供查询、问答和报告使用。
归组任务从确认内容选择候选，保存主题成员及依据。
具体联系需要两端正文支持，按独立预算处理。

每次模型请求检查许可、并发、价格时段、额度和重试次数。
失败保留已完成阶段。人工暂停、拒绝和版本冲突等待人工处理。
