# 往期补收

在源管理打开“补收往期”。
选择来源、发布日期范围和每个来源的数量上限。
先查询目录，再预览正文并选择资料，最后加入待审核队列。

查询支持 RSS/Atom、同站点 Sitemap、公开归档页，以及已识别站点的分页目录。
可填写当前来源的公开归档地址。
不同来源的历史覆盖范围按其公开目录决定。

## 操作

结果可按来源筛选。选择跨页保留，数量限制分别应用到每个来源。
检查日期、正文完整性和重复记录后提交。
补收材料保存来源、原始日期、接收渠道和去重身份。
已有人工决定与原始证据保留。

目录会话存在有效期。中断后可以重新查询。
请求按来源限速，失败时保留状态。
仅目录查询会读取公开元数据；正文采集发生在预览或补收操作。
实时订阅游标与补收进度分别管理。

补收默认进入待审核。审核后再选择整理任务。
批量自动处理另按用户选定范围和模型预算执行。
来源清单、原文、目录结果和运行记录保存在个人工作区或外部操作目录。
