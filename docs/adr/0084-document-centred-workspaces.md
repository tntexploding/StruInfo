# 0084 — Document-centred workspaces

Status: implemented (2026-09-19).

The owner replaces the former inbox/library/topic/query workflow with four
primary workspaces: document entry, workbench, data reading and reports. Keep
the rounded surfaces and semantic palette. Overview remains on the logo;
settings moves to the bottom of the navigation.

Document entry groups received material by subscription, explains each source
through its configuration and received articles, and keeps full reading and
receipt decisions together. Workbench keeps the document visible while manual
edits remain drafts until an explicit confirmation. Existing confirmed content
remains available until a revision succeeds. Immutable source evidence is never
edited. AI actions use existing durable tasks, grants, budgets and price gates.

Data reading combines search, the selected item's relationship graph and cited
AI answers. Reports keeps selection settings alongside its durable task/history
list. Publication is local Markdown or print-to-PDF; no delivery channel is
connected. Source scope, privacy, global unattended policy and model dispatch
permission do not change implicitly.

Navigation animation reflects observed running work and completion transitions,
never elapsed-time progress. Waiting, denied and failed tasks do not animate as
active work. Reduced motion retains static state indications.

Validation uses synthetic content and read-only browser checks. Existing owner
data and pre-existing repository changes must be preserved. No commit or push is
part of this increment.

## Implementation boundaries

- Source purpose is an optional external subscription description; received
  article titles provide concrete history without inventing a publisher profile.
- Intake translation is transient and does not accept a document or write an
  Entry. Receipt review remains acceptance-only. The contextual recovery panel
  retains previous captures and explicit task continuation.
- Manual structure uses the existing complete ordered Unicode partition and
  revision/preview boundary. AI retagging uses bounded durable tasks; translation
  regeneration compares the saved timestamp as well as the Entry revision.
- Natural questions retrieve bounded public evidence before synthesis. Local
  lexical recall remains available without a vector index. Answers retain exact
  citation return.
- Reports support daily, weekly, monthly and topical selection, AI composition
  or deterministic excerpts, Markdown download and a revalidated local PDF
  print view. Unlimited editorial selection retains the 512-source capture
  boundary and existing model budgets.

This increment adds no migration or dependency. Existing Agent grants and
external workspace material remain unchanged.
