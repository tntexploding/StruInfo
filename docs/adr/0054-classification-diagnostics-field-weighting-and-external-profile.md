# ADR 0054: 分类诊断、字段权重、多领域与外部规则

- 状态：Accepted
- 日期：2026-08-31
- 里程碑：M2-P2A–P2D

## 背景

M2-P1C 首次对真实规模批次补齐类型与领域后，14,910 条 Entry 中只有 3,768 条具有类型、
8,951 条具有领域，同时 12,613 条只得到统一的 classification_incomplete。该结果证明“不猜测”
边界有效，但也暴露了四个直接影响后续改进的问题：

1. 无信号、只缺一个维度、平局和低置信度被合并，无法按原因统计和抽样；
2. v1 把标题、关键词和正文拼接为一段 Boolean 文本，没有表达字段强弱；
3. 一个 Entry 只能得到一个领域，无法表示主领域和有限的跨领域事实；
4. 所有者的别名、术语映射和噪声排除无法在不改代码的情况下参与批处理。

这些属于可达产品缺口。M2-P2E 的残余 Codex 复核和 M2-P2F 的 UI 覆盖率/纠错工作台需要先看
P2A–D 在现有数据上的实际刷新结果，因此不在本决策中提前实现。

## 决策

### P2A：可统计的闭合诊断

保留旧 classification_incomplete 以读取既有记录，并新增四个稳定异常代码：

- classification_no_signal：类型和领域都没有规则信号；
- classification_type_missing：领域已形成，只有类型缺失；
- classification_domain_missing：类型已形成，只有领域缺失；
- classification_tied：平局、低于阈值或领先幅度不足，不能安全确定主分类。

既有 adjudication summary/sample 按异常代码分组，因此无需第二套诊断表或报告服务。
迁移 000030 只扩展原异常代码 CHECK，不增加表、正文或开放 payload。

### P2B：字段感知的确定性分类 v2

分类器分别观察标题、当前内容关键词和最多 32,000 字符正文。内建信号按标题 ×3、关键词 ×2、
正文 ×1 计分；有限结构线索可小幅加分，明确相反信号可扣分。主分类必须同时达到最低分 6，
并至少领先第二名 3 分；否则输出诊断而不是猜测。外部显式术语映射使用更高但仍确定的字段权重。

规则保持纯本地、无 Provider、无随机数。enrichment 仍只填补空的类型/领域，绝不覆盖人工、AI
或导入分类。

### P2C：一个主领域和最多两个次领域

只有主领域通过上述阈值和领先幅度后才输出领域。主领域始终排第一；其他候选必须至少达到最低分
6 且不低于主领域一半，按分数和稳定关键词顺序选取，领域总数最多 3。现有 Entry 数据结构已经
把第一个领域解释为 primary、后续解释为 secondary，因此不需要迁移或第二种表示。

### P2D：外部个人分类配置

ReviewPreferences 增加可选 struinfo.entry-classification-profile v1：

- 大小写无关、一次规范化后的别名；
- term → type 映射；
- term → domain 映射；
- 在分类前移除的噪声词。

配置具有显式 revision、数量和词长上限，拒绝未知字段、重复项、别名环和 other 映射。它保存在
所选外部数据根的个人偏好文件中，并由现有完整个人数据包携带；旧文件和旧包缺少该字段时升级为空
配置。规则摘要包含整个 Profile 内容，因此内容变化会使显式 enrich-refresh 识别为新规则。
Git、数据库、日志和应用制品不保存所有者词表。

## 结果与操作边界

- P2A–D 只使用合成测试交付，不读取、恢复或修改真实工作区；
- 升级已有环境时先停写备份，应用 000030 和 runtime grants，再对目标成功批次显式执行
  enrich-refresh / enrich-resume；
- 刷新后用既有 adjudication summary 比较四类诊断、类型覆盖率、领域覆盖率和多领域分布；
- 在获得该真实结果前，不实施 P2E 大批残余人工/Codex 复核，也不实施 P2F UI；
- 该分类仍是可纠正的确定性元数据，不是事实真值、向量语义或正式知识关系。
