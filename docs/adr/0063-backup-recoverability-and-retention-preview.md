# ADR 0063：备份可恢复性校验与保留预览

- 状态：Accepted
- 日期：2026-09-02
- 对应增量：M2-P5B
- 修订：只增加维护侧备份盘点、只读校验和保留预览；不改变产品数据模型或自动删除文件

## 背景

M1M 已能把当前工作区数据库分区、引用 Blob 和个人偏好写成外部完整个人数据包，并且只允许恢复到
同 workspace 的空业务数据库。M2-P5A 又区分了公开发行、当前开发代码和所有者确认已经运行的
私人云端实例。但生产维护仍缺少三个直接可用的动作：查看当前 workspace 有哪些备份、在不恢复的
情况下确认某份备份完整可读，以及在真正删除前看清一个保留数量会影响哪些文件。

备份文件名、摘要、数据内容、云端路径和恢复演练结果都属于外部运维状态，不能写入 Git。项目也不应
在所有者尚未决定异地副本、时间窗口和容量预算前擅自执行自动删除。

## 决策

### 1. 当前备份目录可以按 workspace 盘点

维护入口新增 `backup list --limit <1..100>`。它只读取外部数据根 `backups/` 的直接普通文件，只识别
当前格式的 `*.personal-data.json`，按文件名中的规范导出时间从新到旧返回文件名、导出时间和字节数。
其他 workspace、旧格式、临时文件、目录、链接和无效时间戳不会进入结果。

该命令不要求数据库当前 ready，不读取文档内容，也不返回外部数据根的绝对路径。

### 2. 可在恢复前完整只读校验指定备份

维护入口新增 `backup verify --file <safe-name.personal-data.json>`。校验复用正式 restore 的同一解码和
闭包逻辑，检查：

- canonical Bundle 信封、受支持 section 版本和同 workspace 身份；
- Domain、Entry、Association、Processing 表投影与跨 section 依赖；
- Blob reference 清单及完整个人数据包内嵌 Blob 的长度和 SHA-256；
- 外部个人偏好的闭合结构与 workspace 身份；
- 整个备份文件的 SHA-256、导出时间、Blob 数和总表行数。

当前自包含个人数据包的校验不写数据库、Blob 或偏好。旧版未内嵌个人数据的 Bundle 只有在其引用的
外部 Blob 仍可完整读取时才算可恢复。校验不要求活动数据库 ready，因此数据库故障时仍能检查恢复
材料；运行配置仍须能定位同一个外部数据根和 workspace。

### 3. 保留策略先预览，应用不自动删除

维护入口新增 `backup retention-preview --keep-latest <1..10000>`。它以当前 workspace 的当前格式备份
为集合，保留最新 N 份，将其余文件列为 removal candidate。报告给出总数、保留数、候选数以及最多
100 个候选文件名；超过时明确 `truncated=true`。

本增量不提供 prune/delete 命令，也不把 N 固定为项目默认值。所有者必须先核验最近备份、决定至少
一个独立副本和恢复目标，再在外部运维流程中对精确文件执行删除。无关文件和其他 workspace 文件永远
不属于预览候选。

### 4. 受控恢复演练继续使用唯一正式 restore

恢复演练不建立第二套导入器。操作方应在仓库外记录运行版本、时间、原备份摘要、计数和结果，并在
隔离的空数据库与数据根中执行：完整迁移、queue 准备、runtime grant、preflight、`backup verify`、
现有 `restore --file`、恢复后 preflight/健康检查，以及一次新的 backup/verify。原备份与恢复后备份的
Blob 数和表行数应一致；文件摘要可因导出时间不同而不同。

真实生产备份文件名、摘要、域名、数据库 URL、数据根、凭据和演练记录不得提交到 Git。仓库内合成
测试只证明工具行为，不冒充私人云服务器上的实际恢复证据。

### 5. 范围

M2-P5B 不增加迁移、依赖、HTTP API、Web 页面、后台调度、远端对象存储、自动保留、跨 workspace
恢复或非空数据库合并。下一生产增量是 M2-P5C 的健康、容量、失败任务和备份年龄可见性。

## 结果

- 操作方可以在数据库不可用时盘点和完整校验现有恢复材料；
- 保留决策在任何删除前可见，应用不会擅自删除个人备份；
- restore 继续只有一个正式实现，校验与恢复不会产生两套格式解释；
- 真实生产记录继续位于外部运维记录，仓库保持无个人数据。

## 验证

- 合成文件系统回归覆盖 workspace 过滤、时间排序、数量限制和无删除保留预览；
- 合成个人数据包回归证明 verify 返回文件摘要/导出时间/计数，且不会调用数据库 restore；
- maintenance 回归覆盖三条新命令、边界输入、脱敏报告以及不调用数据库 readiness；
- TypeScript、格式、单元/集成、构建、制品与部署静态检查继续由仓库质量门执行。
