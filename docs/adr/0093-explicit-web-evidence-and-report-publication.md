# ADR 0093：联网证据与报告发布

- 状态：已接受
- 日期：2026-10-24
- 阶段：P6

## 问题

库内问答需要保留筛选范围，同时可以使用新鲜的网页证据。网页摘要不能直接变成库内文章。
已有报告生成器读取最新正文，不能固定生成时的证据。生成、发布和周期调度需要分别记录。

## 决定

1. 采用所有者指定的 DeepSeek Search / Fetch，复用密钥和执行门禁。供应商地址固定，不跟随认证重定向。
2. 公开搜索词单独输入，不自动发送库内文本。网页先保存在短时会话，显式保存才进入待审核。
3. 搜索、抓取按次记录预留和估算费用，受独立日请求上限及共享 AI 并发约束。未知结果不自动补发。
4. 复用现有回答校验与报告生成器。新报告保存固定正文摘录和版本；旧报告保留原版本检查。
5. 定时配置属于个人工作区。任务和周期确定幂等编号，并固定执行时的配置版本；生成、站内发布和通知独立持久化。
6. 定时 AI 报告显式绑定预算；只读状态、原文摘录报告和基础站内通知不调用模型。
7. 外部推送没有已配置渠道。本阶段只实现站内通知、Markdown 和打印 PDF。
8. 新增兼容迁移和备份版本。恢复默认停用新的联网与调度权限，不自动恢复运行。

## 信任边界

网页文本、摘要和标题都是不可信证据。回答提示不执行其中的指令；引用编号必须来自当前证据集合。
搜索结果 URL 限制 HTTP/HTTPS、公网主机、无用户名密码和常规端口，过滤本地和私网地址。
供应商凭据只发送到固定的 DeepSeek 域名，不发送给结果网站。页面抓取由 DeepSeek Fetch 执行。
响应流、候选数、正文长度、会话数量、存活时间和日请求数均受限。
私有查询禁止出站；缓存回答和发布通知继续检查当前可见性，禁止以历史缓存绕过隐私设置。
模型请求与按次查询分别记账；供应商错误正文和密钥不写入错误消息、Git 或通知。

## 验证

使用合成搜索／模型、临时数据库和合成浏览器页面验证。工程检查不代表搜索相关性或模型语义准确率。
真实搜索费用和检索质量留给后续明确授权的小批验收。
