# ADR 0060：类别均衡的类型学习与全量投射激活门

- 状态：Accepted
- 日期：2026-09-02
- 对应增量：M2-P4D
- 修订：取代 ADR 0059 中较宽松的抽样、权重与激活门；其余可信样本和外部 Profile 边界保持不变

## 背景

首次真实规模的两轮隔离标注没有写入 Entry，也没有激活模型，但暴露出四个问题：候选按缺失状态和
Snapshot 顺序集中于事实材料；少数类别缺少独立支持；加一平滑会让零或少正样本类别获得不合理高权重；
只检查选择性 precision 无法发现全量缺类型 Entry 上的覆盖过低或单类坍缩。写入隔离是有效的，但抽样和
激活规范不足以安全复用这些结果。

## 决策

1. 主动抽样先补类别缺口。一个工作包最多 75% 用于尚未达到支持门槛的已有类型 Entry，并优先来自尚未
   覆盖的 Snapshot；剩余候选按模型分歧、低领先幅度、预测类别或结构特征分层轮转。工作包中的
   `targetTypeKeyword` 只是审阅提示，不能成为可信标签。
2. 每个可学习类别至少需要 8 个可信样本、6 个 Snapshot；其中训练至少保留 6 个样本、4 个 Snapshot，
   验证至少包含 2 个样本、2 个 Snapshot。候选至少需要 4 个满足支持量的类别。支持不足或零样本类别
   必须禁用，不得通过平滑产生模型权重。
3. 特征权重使用有界的正负样本观测率差，不使用加一平滑；单个权重上限为 8,000，每类训练最多均衡取
   64 个样本，避免大类仅凭数量压倒小类。确定性规则仍始终先于学习模型。
4. 验证集必须同时满足：全局 precision 不低于 92%、coverage 不低于 15%；每个支持类别至少真正赋型
   2 条且 precision 不低于 85%。按 Snapshot 隔离仍然有效。
5. 候选还必须投射到当前同一隐私范围内的全部缺类型 Entry。总体至少有 20 条、coverage 不低于 15%、
   至少产生 3 个类别，且任何一个类别不得超过全部模型赋型结果的 50%。投射只保存聚合量和绑定当前
   Entry revision 的摘要，不把正文写入偏好文件。
6. 显式激活前重新加载当前 Entry，使用同一可信样本和隐私范围重训，并逐字节比较完整模型、评估和全量
   投射摘要。数据或 Profile 漂移、支持量不足、分布坍缩均返回不合格，不得激活。
7. 旧模型仍可由外部 Profile 解码和备份，但缺少 `struinfo.entry-type-learning.activation.v2` 标记的候选
   或激活模型不得进入运行时。它们必须在新规则下重新训练；不自动删除可信样本，也不修改任何 Entry。

## 后果

- 前两轮隔离标注继续留在候选边界之外，不会影响真实分类；
- 少量样本不再制造高置信类别，类别不均衡会在抽样阶段得到直接反馈；
- 一个验证集上的高 precision 不再足以激活会在万级数据上坍缩的模型；
- 本增量没有迁移、新依赖、Provider/API、UI、后台任务或真实资料写入，正式补全仍复用 P0B/P2G。
