## 使用阶段的维护节奏

- 正常使用时按需刷新公开索引，集中处理来源复核，保持 AI 提案显式接受。
- 每 6 小时读取健康、容量、任务失败、索引缺口和备份年龄；状态正常且不变时保持安静。
- 已校验备份满 24 小时后，下次巡检会执行一次备份；使用短暂停写窗口，随后恢复服务、完整校验并复制到独立目录。只追加，不自动删除既有备份。
- GitHub 每周一北京时间 10:17 检查生产依赖和构建镜像，也可手动触发；保留失败为失败，不自动更新、放宽忽略或部署。
- 本次系统镜像扫描有 56 条告警（18 个 CVE），当前入口未发现可达触发，按 [DH-013](deferred-hardening-memo.md#dh-013-base-image-scanner-findings-outside-the-current-runtime-path) 跟踪；这不是零漏洞结论。
- 月度确认巡检和安全工作流仍启用、最近运行确实完成且发现已复核；公共仓库长期无活动时应留意 GitHub 停用定时工作流。
- 升级前创建恢复点；出现容量、恢复目标或跨进程部署需求时，单独接受对应边界。

## 使用验收

合成发行回归贯穿导入、拆分、标签、联系与查询；真实备份的隔离恢复副本通过查询分页、
精确来源、命名查询与重启恢复、绑定版本的来源复核、引用式 Markdown 预览/导出校验。
这些检查未调用 Provider，也未把演练变更写入正式实例。首次一至两周的真实使用观察
在使用阶段继续，只记录具体任务、预期、实际、时间和可复现条件。
真实 Provider 质量与费用仅在实际启用时观察，不把合成回归视为内容质量验收。

任何多进程共享数据根方案先处理[DH-012](deferred-hardening-memo.md)；
备份副本位于同一宿主只证明目录级恢复准备，不作为异地或整机灾难恢复证据。

本机维护调度依赖电脑开机、Codex 运行及 Docker 可访问；依据[调度说明](https://learn.chatgpt.com/docs/automations?surface=app)，
它不是离线或独立宿主告警服务。正常状态和已知不变告警保持安静，新问题、恢复或需要
所有者处理时才提示。
