# 结构化标签与标注

结构化标注支持人工编辑和模型生成，保存原文依据。

## 配置词表

在文档阅读中选中条目并打开标注操作。词表在设置页管理。
可以启用六个起始维度：内容形式、领域、具体对象、核心议题、使用目的、适用条件；
也可以添加自己的维度。保存后，后续 AI 标签请求使用已启用的维度。
空词表不改变已有标签流程，关闭全部维度可停止后续结构化生成。

每个词条有固定身份、名称、含义和维度。相同名称可以表示不同对象。
已有词条的身份和含义保持不变，改义时新建词条，再记录二者关系。
AI 提出的新词先属于当前条目，可通过“加入词表草稿”纳入公共词表。
实际维度、词条、别名和关系保存在外部个人配置中，随个人数据包备份。
词表用于公开资料的模型输入，请只放可以发送给模型的内容。

别名、译名和词条关系先保存为待确认状态。确认的别名及“同一含义”关系参与同义检索；
“相关”“上位词”单独保存，不扩展成同义词。确认可撤回，原标注不改写。
同名词条不会按名称自动合并，也不会从历史标签批量推断同义关系。

## 标注一条内容

1. 在“本条标注”选择维度和词条，或填写新词的名称、含义及原文称呼。
2. 粘贴支持这项标注的正文原句，选择主要或次要归属，添加到本条。
3. 原文明确提出观点时，填写主张、提出者、立场、条件、时间和原句。没有依据的字段留空。
4. 选择标注结果和阅读状态，保存草稿，再确认文档。

标注结果包括已标注、部分已知、暂不确定、无需标签。后两种状态可以不带标签或观点，
不影响基础确认。阅读进度包括未读、在读、已读、已归档，仅记录阅读状态，不删除文章。
保存标注会产生条目修订；确认前，查询仍使用上次确认的内容和标注。
正文修改后，旧标注会显示“需核对”，不再参与标签分类匹配。原引用仍保留以便检查。

依据使用当前条目正文中的 Unicode 字符范围和逐字引用。编辑器要求原句在正文中唯一可定位；
接口也可以明确提供重复原句的具体范围。引用不能来自其他条目、前言或未读取的外链。
格式和范围校验能发现错误引用；标签是否准确概括原句、观点是否忠于原文仍需语义检查。

## AI 与外部 Agent

启用维度后，内置 AI 在原有标签请求中同时返回结构化标注和明确观点，不新增一个模型调用阶段。
一批共用一份词表，最多传入 32 个启用维度和 128 个已配置词条，词条还受输入容量限制；完整词表可保存 4,096 个词条。
未提供的词条可作为当前条目的新词提出，系统不按拼写相同自动归并。
每条最多 48 项标注、16 项明确观点。模型输出须通过结构、正文引用和输入修订检查。
调用仍遵守既有许可、价格、并发、重试和额度。已保存的旧提案不重跑。
人工保存过的结构化标注由人工维护，后续 AI 提案保留这些修改。

HTTP 与 MCP 共用以下用例：

| 操作                         | 用途                 | 权限                                        |
| ---------------------------- | -------------------- | ------------------------------------------- |
| `annotation_vocabulary`      | 读取维度、词条和别名 | `documents.read`                            |
| `entry_annotations_read`     | 读取条目草稿及词表   | `documents.read`，隐私另行检查              |
| `entry_annotations_save`     | 版本检查后保存草稿   | 所有者 `entries.revise`；Agent `agent.tags` |
| `annotation_vocabulary_save` | 保存词表配置         | 仅所有者 HTTP                               |

保存草稿须提供条目修订 `expectedRevision` 和词表修订 `vocabularyRevision`。
确认继续调用 P1 的 `document_publish`，不由模型或标注接口直接发布。

## 查询与兼容

数据阅览的“筛选与匹配方式”增加结构化分类：维度、词条、标注状态和阅读进度。
普通标签搜索支持原称呼、词条名称、确认的别名和同义词。筛选也可保存为查询。
查询游标绑定筛选条件和词表版本；修改词表后应重新查询。
没有标注的旧条目仍可正常浏览，可单独筛选“未标注”。

迁移 `000041` 增加条目标注和模型提案载荷两张表；发布快照保存确认时的完整标注。
Entry Bundle v8、Processing Bundle v17 保存新记录，并继续读取旧版本数据包。
恢复保留草稿、已确认标注和历史模型提案，后台归组待办仍保持暂停。
主题与重点联系通过独立归组任务处理。
