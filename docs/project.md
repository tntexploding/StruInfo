# 项目说明

## 功能

StruInfo 是单所有者的文档知识库，当前源码版本为 v0.5.0。
支持来源接收、手动导入、文档整理、分类检索、知识库问答和报告。
模型接入可选。外部 Agent 通过 HTTP 或 MCP 操作共享应用用例。
运行环境为 Node.js、HTML/JavaScript、PostgreSQL 18，可用 Docker 部署。

## 内容流程

来源组件采集原始资料。接收层保存原文、来源、日期和接收记录。
审核通过后，新文档任务按来源方案拆分，生成结构化标注，再确认发布。
人工已确认的接收决定保留。修改正文、结构和标注后形成草稿，确认时检查修订。
查询、问答和报告读取已确认内容。后续草稿与确认版本分别保存。
主题归组和重点联系使用独立任务与预算。归组失败保留基础发布结果。
连贯文章保留上下文。合集按独立内容拆分，附属内容随正文保存。
标签、观点和联系绑定原文依据。人工修改优先。
旧文档任务可读取、取消；新任务采用 confirmed-content-v1。

## 页面

| 页面     | 内容                                              |
| -------- | ------------------------------------------------- |
| 总览     | 标识、统计、流程、AI 中控、队列和消息             |
| 源管理   | 唱片选择器、来源配置、接收安排、AI 方案和近期接收 |
| 文档阅读 | 原文、段落、标签、联系、主题和人工确认            |
| 数据库   | 分类、搜索、问答、联网研究和报告                  |
| 设置     | 外观、词表、处理规则、模型、通知和数据维护        |

来源策略、拆分方案、词表、主题、报告和偏好保存于个人工作区。
模板与合成示例可入 Git。模型请求受许可、价格时段、并发和额度限制。
私密资料留在本地。网络内容和模型输出按输入数据处理。
联网结果显式保存后进入待审核。定时和联网能力默认关闭。
报告支持站内发布、Markdown 导出和浏览器打印 PDF。
系统助手通过共享接口操作来源、文档、查询、报告和任务。支持多步执行、持久会话和写入确认。
网页与消息适配器共用助手；入口使用独立密钥。后台队列开关与助手调用分开。
外部推送、多租户和集群写入尚未交付。

## 代码位置

| 目录                                        | 职责                   |
| ------------------------------------------- | ---------------------- |
| apps/server/src/application                 | 共享用例、任务与发布   |
| apps/server/src/modules                     | 内容规则               |
| apps/server/src/platform                    | 数据库、来源和模型适配 |
| apps/server/src/transport                   | HTTP 与 MCP            |
| apps/server/src/composition                 | 运行装配               |
| apps/server/src/storage、workspace_transfer | 偏好、文件和恢复       |
| apps/web                                    | 页面、控件和主题       |
| packages/contracts                          | 外部协议               |
| apps/server/migrations                      | 已发布迁移             |

写操作通过应用用例执行。确认发布保留版本冲突检查。
应用账号与迁移账号分离。迁移向前执行，旧迁移保留原字节。
备份包含数据库内容、引用原文和偏好。恢复使用同身份的空工作区。
