# StruInfo v0.5.1

长文按段建立向量索引，检索结果可以定位到原文。主题按需生成，可从聚合和报告进入。快讯经审核后单独展示。

来源接收支持分页和断点续读。文档任务修正了配置读取与调度唤醒，标签引用能定位到本次处理的条目。合集拆分保留子条目标题和来源边界。结构不清的合集仍可交给人工审核。

## 升级

1. 备份 PostgreSQL 和仓库外的工作区文件。
2. 选择同版本的应用镜像和维护镜像，使用维护入口执行待应用的数据库迁移。
3. 启动应用，在设置中查看索引进度。向量服务需要配置接口与额度。

部署命令见[运行维护](../production-operations.md)。迁移覆盖分块向量、按需主题和快讯索引清理。
