# StruInfo v0.5.0

2026-10-28

本版完成内容系统重构和五页界面对接。

## 使用变化

- 总览集中展示统计、处理流程、AI 中控和消息。源管理使用唱片选择器，搜索和添加入口固定在唱片内，接收记录从底部展开。
- 文档阅读使用全文与旁注布局，编辑入口集中；数据库保留居中搜索、可收起的范围与报告侧栏；设置按用途分组。
- 接收、拆分方案、结构化标注、主题和报告使用统一的 HTTP / MCP 应用用例。
- 新文档任务完成审核、拆分与标注后确认发布。主题和重点联系单独执行，使用显式预算，不阻塞正文查询。
- 来源拆分方案支持试读、启用和格式变化复核；个人词表、来源提示、调度和报告配置均保存在外部工作区。
- DeepSeek Search / Fetch 支持网页证据、混合问答和显式保存待审核。报告固定引用，生成与站内发布分开。联网和定时任务默认关闭。

## 已清理的旧路径

移除独立条目自动分流执行器及其页面、接口，移除旧偏好评分面板和接口。
新来源不再提供导入后分流开关或失败重试间隔；接收后统一进入审核流程。
旧文档任务可查看和取消，不再继续旧的逐篇联系流水线。需继续的资料应重新创建新文档任务。
历史备份和任务格式保留读取能力；这部分不再创建活动任务。

## 安全修补

更新 MCP、Vite、Vitest、请求解析器及其关联依赖，修复本次审计发现的漏洞。
锁文件、归属声明和 SBOM 已同步，安装脚本保持禁用。

## 从 v0.4.0 升级

1. 停止应用写入，用旧版本创建并校验完整备份，同时保留旧镜像。
2. 构建 v0.5.0 镜像。保留工作区 ID、数据库、原文目录和外部密钥配置。
3. 执行 `migrate`、`prepare-queue`，重新应用 `deploy/postgresql/apply-runtime-grants.sql`。
4. 执行 preflight，启动一个 `all` 实例，核对健康、原文、已确认版本、来源设置和任务。
5. 检查自动处理范围与预算。旧任务不会自动转成新任务，旧预算不会自动续额。

包含迁移 000040–000043 和 Processing Bundle v19。迁移为前向；回退使用旧镜像和迁移前备份恢复到空目标。
新库使用者直接初始化，无需导入封存库。源码发布不自动更新私人 Docker 实例。
详细命令见[运行维护](../production-operations.md)。

## 边界

面向单所有者、单实例。保留原文、人工决定、隐私隔离及 AI 许可、价格、并发和费用限制。
本轮使用合成材料和临时数据库验收，不调用付费服务。真实模型处理质量与费用仍由选定材料的有限运行验证。
系统助手尚未实现；外部 Agent 继续通过已授权 MCP / HTTP 接口操作。外部推送渠道未配置，支持 Markdown 和打印 PDF。
