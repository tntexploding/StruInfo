# StruInfo v0.2.0

- 状态：维护源码版本；提交与运行结果见[维护交接](../maintenance-handoff.md)
- 日期：2026-09-05

当前已接受的产品范围完成，常规功能开发暂停。维护优先处理实际使用中可复现的缺陷、
安全问题和运行兼容性；类型学习 M2-P4R 及其他候选继续冻结。

## 相对 v0.1.0 的变化

- 可恢复的批量物化、确定性标签/联系、分类异常复核和有限窗口推进。
- 按证据优化浏览分页、索引状态和图谱邻域读取。
- 公开 Entry 增量索引刷新，支持本批后暂停、继续、失败重试和向量复用。
- 外部版本化命名查询与当前阅读位置，重新打开隐私范围仍需显式选择。
- 关系来源复核列表、双端精确来源及端点 revision 绑定。
- 明确选择最多 20 个 Entry，预览并生成带精确引用的 Markdown 文件。
- 备份盘点/校验、保留预览、运行状态和定期安全检查。
- 将 qs 固定到 6.16.0，修复两项生产依赖安全通告；基础系统告警的可达性核对见维护交接。
- 修复查询切换旧结果操作、页码错位和偏好恢复并发问题。

## 升级与兼容

升级前停写并创建、校验备份。执行全部前向迁移至 000031、queue 准备、runtime grant
和 preflight，再启动应用。来源复核使用 Association Bundle v5，旧包继续可读；
旧核验记录不补造端点版本。索引按实际缺口刷新，不自动调用 Provider。

恢复演练使用相同 workspace 的隔离空数据库和外部数据根；回退使用升级前备份与
对应版本，不能在非空生产数据库上倒退 DDL。完整步骤见[运维手册](../production-operations.md)。

## 保持的边界

私人单用户、all 单实例和受控网络边界继续成立。原始证据不变，隐私默认收敛，
AI 提案需明确接受。个人数据、凭据、运行配置、备份和实际实例身份只在仓库外保存。
公开版本与私人实例分别核验，不根据标签推断已部署。
