## 使用

1. 在“查询”中选中条目，展开“资料清单与导出”，点击“加入资料清单”。
2. 可以在同一查询中翻页继续加入，最多 20 条；清单顺序就是导出顺序。
3. 填写标题并点击“预览资料清单”，查看条目版本、隐私范围、引用和关系。
4. 点击“生成 Markdown 文件”；含隐私范围使用明确的“含隐私生成”按钮。
5. 文件已保存到当前工作区的外部 `exports/`，可再点击“下载 Markdown”保存到本机。

修改查询条件、关联锚点或隐私范围，以及离开查询页，都会清空会话选择和预览。
翻页保留选择；删除清单项目或改标题会使预览失效。
清单不会自动收集全部结果，也不把完整私密文档结果或 AI 综合答案加入清单。
已发出的生成请求可能在导航后完成，但迟到响应不会重新显示内容或恢复下载链接。

## 内容与来源

每项导出当前标题、Entry/revisionId/revision、Resource、Snapshot、来源标识/地址、采集时间和已知发布时间。
缺失发布时间明确为“未提供”，推断时间保持推断与精度标记。
当前条目正文最多摘录前 1,200 个 Unicode 字符，并明确截断；它可能经过人工修改，不能冒充原文。

原始来源总计最多摘录每项前 600 个 Unicode 字符，直接从本地 Blob 和不可变 Fragment 重建。
全部引用仍列出 Structure、Fragment、文本摘要、Fragment 内范围与结构全文范围。
范围均为半开 Unicode 标量区间 `[start, end)`，有截断的引用额外标明实际摘录终点。
没有 range 行的既有条目继续使用完整 Fragment。
来源中的 HTML、图片和链接作为字面文字，不在预览或正文摘录中执行或加载。

关系只包含两端都在清单中的当前可见关系，保留方向、语义、真实来源、维护说明、关系版本和有效来源复核状态。
自动相似、人工编辑和 AI 辅助分别标注；旧核验缺少版本绑定或端点发生变化时仍显示需复核。
隐藏关系和过期计算投影不导出，不创建关系或事实核验结论。

## HTTP 与一致性

两个同源接口沿用现有本地 API 安全响应头与 `no-store`：

| 操作 | 路径                                           | 返回                                                           |
| ---- | ---------------------------------------------- | -------------------------------------------------------------- |
| 预览 | `POST /api/v1/entries/markdown-export/preview` | `ready`、完整 Markdown、版本清单、范围、数量、字节数与 SHA-256 |
| 生成 | `POST /api/v1/entries/markdown-export`         | `exported`、相同内容和安全文件名                               |

请求只接受标题、`privacyScope` 和 1–20 个互不重复的 `{entryId, revision, revisionId}`。
标题最多 120 个 Unicode 字符，不接受空标题、控制字符、路径、客户端正文或任意查询。
生成额外要求预览的 `expectedSha256`；该摘要只绑定预览内容，不能替代隐私与版本检查。
总文件上限为 2 MiB，超限明确返回错误，不静默丢弃条目或引用。

PostgreSQL 在既有工作区锁之后读取当前结构与版本，只装载所选条目及清单内关系。
锁保持到本地证据读取和文件生成结束，避免排队期间的编辑绕过版本检查。
服务先核对所有条目与 Snapshot 的可见性，再读取任何 Blob。
生成时重新读取并重建完整内容；Entry 版本变化返回 `selection_stale`，关系或预览内容变化返回 `preview_stale`。
不可见、退役和不存在的条目统一失败，不泄露其他范围的标题或正文。
任何失败都不会退化为部分清单。

文件名由服务器生成，不使用标题作为路径；独占临时文件、同步后重命名，仅返回文件名和字节数。
默认采用所有者读写权限；实际平台权限沿现有外部数据根配置。
浏览器下载来自生成响应的相同 Markdown，离开范围后撤销会话 Blob URL。
不提供任意文件读取接口、目录枚举或公开链接。
